# <project-name>

A data analysis project on agent-teams.

## Quick start
1. Drop your data file(s) into `data/raw/`
2. Open this project in the agent-teams UI
3. From the project page, click 'New task' → pick a template like 'Summarize'
4. The AI agent does the analysis and saves results into `analysis/outputs/<task-id>/`

## Folders
- `data/raw/` — your uploaded files (a `sample_sales.csv` is included as a starter)
- `data/cleaned/` — cleaned/transformed data the AI writes
- `analysis/outputs/` — chart PNG / report MD / export CSV per task
