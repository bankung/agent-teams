# <project-name>

A social content project on agent-teams. Drafts content for: Facebook, X/Twitter, TikTok, Instagram, LinkedIn, YouTube Shorts.

## Quick start

1. (Optional but recommended) Fill in `voice.md` — your brand voice + audience
2. Drop reference images/videos into `media/`
3. Click 'New task' → pick a template like 'Draft X thread'
4. Review the AI's draft in the task drawer
5. Copy the final text to the platform yourself (we never auto-post)

## Folders

- `posts/drafts/` — AI agents write draft posts here per task
- `posts/ready/` — your final versions, moved/curated by you
- `media/` — brand images/videos/GIFs to reference in posts
- `voice.md` — your brand voice profile (recommended to set up)

## Sample

`posts/ready/sample-linkedin-post.md` is a placeholder LinkedIn post to show the format. Delete it when you have your own content.
